# Space Orbit: Flexbox Navigator 🚀
> משחק אינטראקטיבי מתקדם ללימוד ותרגול CSS Flexbox | מטלה מספר 2 בקורס פיתוח יישומי אינטרנט

![Space Orbit Game](assets/spaceship-cyan.svg)

## 🌌 אודות הפרויקט
**Space Orbit: Flexbox Navigator** הוא משחק אינטראקטיבי מקורי בנושא פיקוד חלל ותמרון חלליות. 
מטרת השחקן היא לכוון ולנווט ציי חלליות לעבר תחנות עגינה ומסלולי יעד באמצעות שימוש מושכל במאפייני **CSS Flexbox**.

הפרויקט נבנה מן היסוד ב-**Vanilla HTML, CSS, JavaScript** ללא שימוש בספריות חיצוניות או CSS Grid, ועומד ב-100% מדרישות המטלה ותנאי ההצטיינות.

---

## 🎯 עמידה בדרישות המטלה

- [x] **10 שלבים עשירים ומודולריים** (דרישת המינימום: 6).
- [x] **שימוש בכל מאפייני החובה:**
  - `display: flex`
  - `flex-direction` (`row`, `row-reverse`, `column`, `column-reverse`)
  - `justify-content` (`flex-start`, `flex-end`, `center`, `space-between`, `space-around`, `space-evenly`)
  - `align-items` (`flex-start`, `flex-end`, `center`, `stretch`, `baseline`)
  - `flex-wrap` (`nowrap`, `wrap`, `wrap-reverse`)
  - תוספת מאפיינים: `align-content`.
- [x] **שלבים מגוונים:** לפחות 4 שלבים דורשים שילוב של מספר מאפייני Flexbox בו-זמנית להגעה לפתרון.
- [x] **Single Page Application (SPA):** מעבר חלק בין כל השלבים ללא טעינת עמוד HTML חדש.
- [x] **לוח במידות קבועות (460x460px):** הפתרונות והחישובים הגיאומטריים זהים לחלוטין ועקביים בכל רזולוציית מסך, עם התאמת Scale רספונסיבית במובייל.
- [x] **שמירת התקדמות מקומית (`localStorage`):** שמירת השלב האחרון, שלבים שנפתחו/הושלמו וכוכבים.
- [x] **מפת שלבים (Level Selector):** אפשרות לחזור ולתרגל שלבים שכבר הושלמו.
- [x] **מערכת דירוג וניקוד:** 1–3 כוכבים לפי מספר הניסיונות בכל שלב.
- [x] **מדריך Flexbox מהיר (Cheatsheet):** חלונית עזרה עם הסבר על כל המאפיינים בעברית ובקוד.
- [x] **משוב ואנימציות:** אפקט ניעור בשגיאה, אנימציית נחיתה והבזק זוהר בהצלחה, ואפקט קונפטי.
- [x] **מנוע סאונד מובנה (Web Audio API):** אפקטים קוליים פרוצדורליים ללא תלות בקבצי שמע כבדים, כולל כפתור השתקה/הפעלה.

## 🛠️ טכנולוגיות ומבנה הפרויקט

```text
├── index.html              # מבנה סמנטי של האפליקציה, מודאלים ועורך קוד
├── css/
│   ├── style.css           # ערכת נושא Dark Neon, טיפוגרפיה, רספונסיביות ומודאלים

│   ├── game.js             # מנוע המשחק, לוגיקת אימות כפול (CSS + גיאומטריה), localStorage
│   └── ui.js               # טיפול באירועים, סאונד (Web Audio API), קונפטי ורינדור UI
├── assets/                 # גרפיקת וקטור SVG מקורית (חלליות ותחנות עגינה בצבעים שונים)
└── README.md
```

## 🚀 הוראות הרצה מקומית ופרסום ב-GitHub Pages

### הרצה מקומית:
מאחר והפרויקט בנוי ב-Vanilla טהור, ניתן פשוט לפתוח את הקובץ `index.html` בכל דפדפן, או להפעיל שרת מקומי קל:
```bash
# באמצעות Python
python -m http.server 8000

# או באמצעות Node
npx serve
```
ולגשת לכתובת: `http://localhost:8000`

### פרסום ב-GitHub Pages:
1. ודאו שה-Repository מוגדר כ-**Public**.
2. גשו ל-**Settings** ב-Repository -> **Pages**.
3. תחת **Branch**, בחרו ב-`main` (או `master`) ובתיקייה `/ (root)`.
4. לחצו **Save**. האתר יהיה זמין בכתובת: `https://<username>.github.io/<repo-name>/`.
